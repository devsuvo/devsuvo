## 👋 About Me

I'm **Suvo**, a full stack web developer based in **Sylhet, Bangladesh**, building fast, thoughtful websites and web apps that help brands look sharp and work even better.

My expertise spans **React.js, Next.js, TypeScript, PHP, and Laravel**, along with custom **WordPress** development tailored to client needs. I also bring a solid understanding of **UI/UX design** and **SEO**, so what I build not only looks great but performs efficiently across platforms.

For the past **5+ years**, I've worked with clients across the US, Europe, and Bangladesh — shipping everything from WordPress marketing sites to full stack React applications. Right now I'm deepening my JavaScript & data structures foundations and building more with **Next.js**.
